YodaMan Manual

v0.1.0 Documentation

1. Introduction

YodaMan is a professional, full-stack web interface for the context-expert (ctx) CLI. It allows you to easily index your codebases and interact with them using a modern, responsive chat interface with a premium UI.

2. Quick Setup

The fastest way to get started is using the One-Command Setup script:

sh setup.sh

This script will audit your system, install missing dependencies via Homebrew, and launch the GUI automatically.

3. Core Concepts

📂 Workspaces

A Workspace is a directory indexed by YodaMan. Once indexed, the AI remembers its structure and logic permanently.

🔍 Semantic Search

Understands the meaning of your code. Finds logic patterns instead of just exact text matches.

4. Using the Interface

1

Sidebar (Workspace Manager)

Register new repositories, sync changes, and run health checks on your indexed folders.

2

Search Tab

Enter any query to see matching code blocks across all your projects with relevance scores.

3

System Dashboard

Monitor vector storage metrics, active AI models, and real-time indexing telemetry.

5. Pro Tips 💡

  • Keep Ollama running in the background.
  • Use Natural Language questions for better chat results.
  • Run Validate regularly to ensure index integrity.
  • Ignore node_modules and dist for faster indexing.
