# YodaMan Website

This is a static product website for the YodaMan ecosystem.

The site tracks the `0.1.6` release and highlights the shared runtime, desktop, VS Code, and mobile publishing paths.

Open locally:

```bash
open website/index.html
```

Deploy by serving the `website/` directory with the repository root available so links to `../public` and `../docs` resolve.

The downloads section links to local build artifacts and publishing checklists. Replace those links with public release URLs after signed packages are uploaded. Generated desktop installers, mobile bundles, and VSIX files are ignored by git.
