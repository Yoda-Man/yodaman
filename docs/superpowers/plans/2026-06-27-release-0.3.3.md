# YodaMan 0.3.3 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Produce and wire the complete 0.3.3 desktop and VS Code website release bundle.

**Architecture:** Keep package manifests as build-version sources and use the existing electron-builder and website synchronization scripts. Validate metadata before packaging and audit static links after synchronization.

**Tech Stack:** npm, Vite, Electron Builder, VSCE, static HTML.

---

### Task 1: Version metadata

- [ ] Replace product and extension manifest versions with 0.3.3.
- [ ] Update system/public manuals, status bar, README, and website metadata.
- [ ] Update website download filenames to 0.3.3.
- [ ] Verify no product-facing 0.3.2 references remain.

### Task 2: Verification and packaging

- [ ] Run the full Jest suite, Vite build, and release smoke test.
- [ ] Package the VS Code extension.
- [ ] Build macOS ARM64, Windows x64, and Linux x64 desktop artifacts.
- [ ] Sync all generated artifacts into `website/downloads`.

### Task 3: Website release audit

- [ ] Confirm each website download link points to an existing non-empty file.
- [ ] Confirm artifact filenames and package metadata report 0.3.3.
- [ ] Report signing or cross-platform packaging warnings without hiding them.
