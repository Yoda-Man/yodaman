YodaMan Manual

1. Introduction

YodaMan is a professional, full-stack intelligence platform powered by high-performance deep semantic indexing. Unlike rival tools that are limited to single-project analysis or cloud-based data leaks, YodaMan provides a local-first, high-performance engine that unifies all your projects, documentation, and codebases into a single, coherent knowledge base.

2. Quick Setup

The fastest way to get started is using the One-Command Setup script:

sh setup.sh

This script will audit your system, install missing dependencies via Homebrew (Node.js, Python, Ollama), and launch the GUI automatically.

3. Core Concepts

Ecosystem Intelligence

YodaMan doesn't just look at one folder. It understands your entire digital workspace across all disparate projects and documentation.

Semantic Search

Understands the meaning of your code. Finds logic patterns and intent instead of just exact text matches.

4. Using the Interface

1

Sidebar (Workspace Manager)

Register new repositories and manage existing ones. YodaMan automatically detects projects you index via the CLI for seamless synchronization.

2

Search Tab

Perform ecosystem-wide semantic searches. Filter by specific projects or search through your entire unified documentation set.

3

Status Bar

Real-time telemetry showing server health, active Intelligence Engine versions, and the local AI model (e.g., Llama 3) currently in use.

5. Pro Tips 💡

  • Keep Ollama running in the background for low-latency AI response.
  • Use Natural Language questions like "How does the auth flow differ between my services?"
  • Ignore node_modules and dist for significantly faster indexing speeds.

6. Troubleshooting

• Engine not found: Ensure the Intelligence Engine is in your PATH or run sh setup.sh.

• Port Conflict: YodaMan uses ports 5190 (Frontend) and 3090 (Backend).

• UI Refresh: If the interface seems stale, use Cmd+Shift+R for a hard refresh.
